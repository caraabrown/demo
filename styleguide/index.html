Rules — Do / Don't
✓ Typography
Cormorant Garamond for all display headings and large numerals
Raleway for all UI text, buttons, labels, descriptions
IBM Plex Mono for eyebrows, field labels, step counters, monospaced data
Use weight to create hierarchy within Raleway (300 body / 700 labels)
✕ Typography
Never use serif for UI labels, buttons, or field text
Never use Helvetica Neue, Oswald, IBM Plex Sans, or other fonts not in the stack
Never use Cormorant in all-caps
Never use bold weight (600+) in Cormorant — use 300 or 400 only
Never use emoji or multicolor icons
✓ Color
Gold (#c8a96e) on dark backgrounds only — eyebrows, CTAs, progress, callout accents
Accent blue (#2a4080) for interactive states on light backgrounds
Navy (#1a2744) for primary buttons on light backgrounds
Off-white (#efede8) as quiz surface / card hover — never pure white as page bg
✕ Color
Never use gold on light backgrounds (insufficient contrast)
Never use teal, purple, or any color outside the defined palette
Never use gold as body text color
Never use pure black (#000000) as background — use #0f1828
Never introduce new semantic colors without updating this guide
✓ Components
Monochromatic SVG icons only — single stroke color, 1.25–1.5px stroke-width
Border radius: 2px for interactive elements, 4–6px for containers
Selected state: 2px solid #2a4080 (light bg) or 1px solid #c8a96e (dark bg)
Progress bar: 1px height, gold fill, rgba(255,255,255,0.08) track
✕ Components
Never use multicolor, filled, or brand-color icons
Never use drop shadows on cards in light surface contexts
Never use gradients on buttons — solid fills only
Never use more than 2px border on any element
Never mix border-radius values within the same component group
✓ Copy Tone
Grounded and direct — respects the reader's intelligence
Names the real problem (AI bias, screener gatekeeping) without hedging
Strong nouns and verbs — "surfaces," "clears," "flags," "recognizes"
Italic Cormorant used for emotional or rhetorical emphasis in headlines only
✕ Copy Tone
No hype or superlatives ("revolutionary," "game-changing," "powerful")
No vague aspirational framing ("unlock your potential")
No passive voice in CTAs
No em-dashes in UI body copy — use commas or line breaks instead
Never refer to users as "job seekers" in hero/CTA copy — too generic
